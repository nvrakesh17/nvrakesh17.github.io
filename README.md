Personal portfolio for **Rakesh Narla**, Senior DevOps / SRE Engineer.

## Focus
- GCP, AWS and Azure
- Terraform and cloud platform automation
- Kubernetes, GKE, Helm, AKS, ECS and OpenShift
- Jenkins Shared Libraries and GitHub Actions
- Jenkins-to-GitHub Actions modernization
- DevSecOps and software supply-chain security
- IAM, GitHub OIDC and GCP Workload Identity Federation
- Kafka, Zookeeper, Istio, Vault and observability
- Databricks platform enablement

## Run locally

Open `index.html` in a browser, or serve it with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

1. Create a public repository named `nvrakesh17.github.io`.
2. Copy the contents of this folder into the repository.
3. Commit and push to `main`.
4. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`.
5. Your portfolio will be available at `https://nvrakesh17.github.io/`.
